# AdmitPath — Персональный маршрут поступления

Персональный помощник для абитуриентов: диагностика готовности, подбор вузов и план поступления. Проект сделан под кейс LOCUSCASE2.

## Технологии

Next.js 14 (App Router) + TypeScript + Tailwind CSS + Claude API (`claude-haiku-4-5-20251001`)

## Быстрый запуск локально

1. Клонировать: `git clone <url> && cd <папка>`
2. Установить зависимости: `npm install`
3. Создать файл `.env` в корне (скопировать `.env.example`): `cp .env.example .env`
4. Вписать в `.env` свой ключ: `ANTHROPIC_API_KEY=sk-ant-...`
5. Запустить: `npm run dev`
6. Открыть [http://localhost:3000](http://localhost:3000)

## Структура проекта

```text
app/                 страницы и серверные API route handlers
components/onboarding/ Welcome, ProfileSetup, AcademicsAndTests, Preferences
components/steps/    Diagnose, рекомендации, сравнение и roadmap
components/Header.tsx верхняя навигация и бейдж AI-лимита
lib/                 Claude-клиент, token-budget и локальные движки
data/                демо-каталог вузов
```

## Основные функции

- Локальный профиль без пароля и отдельные этапы онбординга.
- Диагностика готовности по GPA, тестам и достижениям.
- Подбор вузов Dream / Target / Safety и сравнение вариантов.
- План поступления с задачами, приоритетами и дедлайнами.
- Черновик мотивационного письма и объяснение рекомендаций через Claude.
- Верхнее меню для перехода между сервисами в любой момент.

## Известные ограничения (для демо)

- Данные по вузам ориентировочные (не live-данные).
- Локальный «профиль» вместо полноценной авторизации.
- Лимит ИИ-запросов на сессию (см. `lib/token-budget.ts`).
