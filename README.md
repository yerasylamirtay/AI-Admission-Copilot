# AdmitPath — AI Admission Copilot 🎓🚀

**AdmitPath** — это интеллектуальный персональный AI-копилот для старшеклассников и абитуриентов, автоматизирующий подбор университетов, оценку шансов на поступление и получение грантов, а также выстраивающий персональный пошаговый план подготовки (Roadmap).

## 🎯 Цель проекта
Устранить хаос и стресс при подготовке к поступлению в университеты Казахстана и зарубежные топ-вузы:
- За **10 минут** помочь абитуриенту понять свои реальные шансы на грант и бюджетное обучение.
- Подобрать сбалансированный список университетов (Dream / Target / Safety).
- Дать готовый пошаговый план (Roadmap) с дедлайнами, шаблонами эссе, рекомендательных писем и полезными ресурсами.

## ✨ Ключевые возможности

1. **AI-интервью вместо статичных анкет**:
   - Живой диалог с ИИ-консультантом, который последовательно задает вопросы, определяет сильные стороны, сданные тесты и автоматически формирует структурированный профиль.
2. **Гибридная диагностика готовности**:
   - Детерминированный математический расчет индекса готовности (0–100%) по весовым коэффициентам (GPA, языки, экзамены, олимпиады).
   - AI-синтез сильных сторон, зон роста и формулировка образовательной цели.
3. **Умный рекомендательный движок**:
   - Персонализированный подбор с гарантированной выдачей минимум 3 вузов даже при строгих фильтрах (авто-ослабление ограничений).
   - Классификация по тирам: **Dream** (вузы мечты), **Target** (оптимальные цели), **Safety** (надежная подушка с грантами).
   - Индивидуальное AI-объяснение «Почему этот вуз подходит именно тебе».
4. **Сравнение до 8 университетов**:
   - Адаптивная таблица с горизонтальным скроллом по всем ключевым метрикам (стоимость, гранты, GPA, тесты, дедлайны, рейтинги, программы, локация).
5. **Адаптивный Roadmap с материалами**:
   - Исключает уже сданные экзамены из списка задач.
   - Включает шаблоны для связи с учителями, структуры эссе (Hook → Journey → Why Us → Impact) и ссылки на порталы вузов.
   - Синхронизация прогресса выполнения в облаке.
6. **Домашний экран (Home Dashboard) & Streak**:
   - Выделенный блок «Твой следующий главный шаг» (ближайший high priority таск).
   - Трекер ежедневных заходов (Streak).
   - Ежедневная ротация мотивационных цитат без лишней траты токенов.

## 🗺️ 7-шаговый флоу пользователя

1. **Шаг 1 — Landing & Вход**:
   - Ценностное предложение, преимущества сервиса.
   - Авторизация через **Email / Пароль** и **Google OAuth** (Supabase Auth).
2. **Шаг 2 — Профиль (AI-интервью)**:
   - Чат с AI-консультантом (до 12 сообщений в сессии).
   - Извлечение данных: класс, интересы, GPA, языки, тесты (IELTS, SAT, ЕНТ), страны, бюджет, сроки, ограничения.
3. **Шаг 3 — Диагностика**:
   - Расчет индекса готовности (Readiness Index) + визуализация факторов.
   - Блоки: *Саммари профиля*, *Сильные стороны*, *Ограничения и точки роста*, *Образовательная цель*.
4. **Шаг 4 — Рекомендации вузов**:
   - Каталог вузов по эшелонам (Dream / Target / Safety).
   - AI-объяснение соответствия профилю и условиям гранта.
   - Выбор до 8 вузов в сравнение.
5. **Шаг 5 — Сравнение**:
   - Сравнительный анализ выбранных вузов в единой интерактивной таблице.
6. **Шаг 6 — Roadmap**:
   - Персональный пошаговый план с датами дедлайнов, категоризацией и прикрепленными ресурсами.
7. **Шаг 7 — Дашборд (Home)**:
   - Центр управления абитуриента, серия заходов, ближайший шаг, быстрый переход к разделам.

## 🔌 Архитектура API и AI-эндпоинтов

| Эндпоинт | Метод | Описание |
| :--- | :--- | :--- |
| `/api/profile-chat` | `POST` | Интерактивное AI-интервью для сбора профиля абитуриента и извлечения структурированного JSON. |
| `/api/diagnose` | `POST` | Расчет детерминированного индекса готовности и генерация AI-резюме (сильные стороны, ограничения, цель). |
| `/api/recommend` | `POST` | Фильтрация и ранжирование вузов по профилю (Dream/Target/Safety) с гарантией выдачи от 3 вузов. |
| `/api/explain` | `POST` | Персонализированное объяснение от Claude, почему данный вуз подходит под профиль студента. |
| `/api/roadmap` | `POST` | Генерация адаптивного плана поступления с учетом сданных тестов и полезных ресурсов. |
| `/api/essay-draft` | `POST` | Генератор черновика мотивационного письма по 4 блокам (Hook, Journey, Why Us, Impact). |
| `/api/token-budget` | `GET` | Мониторинг квоты запросов к AI-моделям. |

## 🛠️ Стек технологий

- **Frontend**: Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS.
- **Backend**: Next.js Serverless Route Handlers.
- **AI Engine**: Anthropic Claude (Claude 3.5 Haiku) с поддержкой отказоустойчивых фоллбэков.
- **База данных & Auth**: Supabase (PostgreSQL, Row Level Security, Google OAuth, Email Auth).
- **Развертывание**: Vercel-ready.

---

## 🗄️ База данных и Supabase RLS

Схема таблиц расположена в `supabase/schema.sql`:
- `profiles` — структурированные профили абитуриентов.
- `diagnoses` — сохраненные результаты расчетов и AI-саммари.
- `recommendations` — персонально подобранные вузы.
- `roadmap_items` — задачи дорожной карты и статусы чекбоксов (`completed`).
- `streaks` — серии ежедневных посещений сервиса.

Все таблицы защищены политиками **Row Level Security (RLS)**: доступ открыт только владельцу строки (`auth.uid() = uid`).

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/yerasylamirtay/AI-Admission-Copilot.git
cd AI-Admission-Copilot
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env.local` на основе `.env.example`:
```env
# Anthropic API Key (для реального вызова Claude AI)
ANTHROPIC_API_KEY=your_anthropic_api_key

# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://ovgualcgjchuuxqownss.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your_google_client_id
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 5. Сборка проекта
```bash
npm run build
npm run start
```
